# Bank Dashboard

Modern banking dashboard built with **React 19** and **Vite**. Includes Dashboard, Transactions, Accounts, Investments, Credit Cards, Loans, Services, and Settings.

## Theme

Deep **midnight** UI with **aqua** and **mint** accents, custom animations, and responsive layouts (mobile, tablet, desktop).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run Oxlint |
